# 기울여라! — 센서 미로 | Tilt & Roll — Sensor Maze

한국어와 영어를 전환하며 플레이할 수 있는 센서 미로 게임입니다. Surface Pro 11을 기울이거나 키보드와 터치로 공을 조작해 5개의 12×12 미로를 통과하세요.

A sensor maze game with Korean and English language options. Tilt your Surface Pro 11, or use the keyboard and touch controls, to guide the ball through five 12×12 mazes.

## 실행하기 | Play

1. `index.html`을 Edge나 Chrome에서 엽니다. | Open `index.html` in Edge or Chrome.
2. 오른쪽 위의 **English / 한국어** 버튼으로 언어를 바꿉니다. | Use the **English / 한국어** button in the top-right to switch languages.
3. 방향키, WASD, 또는 게임판 드래그로 공을 움직입니다. | Use the arrow keys, WASD, or drag on the board.
4. 센서가 지원되는 기기에서는 **기울기 센서 켜기**를 누릅니다. | On supported devices, select **Enable tilt sensor**.
5. 목표에 도착하면 다음 미로로 넘어갑니다. | Reach the goal to continue to the next maze.

센서 지원은 브라우저와 기기에 따라 다릅니다. 센서가 작동하지 않아도 키보드와 드래그로 플레이할 수 있습니다. | Sensor support varies by browser and device. Keyboard and drag controls remain available if the sensor does not work.
